# ScamShield AI — ML Datasets & Provenance

## 1. Message Classification Dataset (`messages`)
- **Primary Public Source**: [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection) (Almeida & Hidalgo, 2012).
  - **License**: Creative Commons Attribution 4.0 International (CC BY 4.0).
  - **Usage**: Public research dataset containing labeled SMS `ham` (normalized to `Legitimate`) and `spam` (normalized to `Spam`) messages.
- **Defensive Phishing & Scam Augmentation**: Curated synthetic phishing and scam examples (including English and Hinglish patterns such as fake KYC, OTP requests, parcel delivery fees, and fake job offers) generated strictly for defensive training without using private user data.
- **Classes**: `Legitimate`, `Spam`, `Phishing`, `Scam`.

## 2. URL Classification Dataset (`urls`)
- **Source**: Curated synthetic defensive URL benchmark generated by `ml_training/prepare_datasets.py`.
  - **Safety**: Contains synthetic URLs only (e.g., `example.com`, RFC-5737/RFC-1918 test IPs, synthetic brand-impersonation patterns). No live phishing URLs are scraped, opened, or executed.
- **Classes**: `Legitimate`, `Phishing`.

## 3. Preprocessing & Leakage Prevention
- Missing/blank rows and invalid entries are dropped.
- Exact and normalized duplicates are removed **before** splitting.
- Stratified `70% / 15% / 15%` (`train / val / test`) split with fixed `random_state=42`.
- Class imbalance is handled via `class_weight="balanced"` during training.
